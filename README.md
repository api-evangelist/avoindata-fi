# Avoindata.fi (avoindata-fi)

Avoindata.fi is a national government open-data portal for Finland running **CKAN**, exposing a standardized catalog API over ~2,521 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/avoindata-fi/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=avoindata-fi-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.11.5

## API
- **Avoindata.fi CKAN Action API** — base `https://www.avoindata.fi/data/fi/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://www.avoindata.fi/data/fi)
- Live endpoint verified: `https://www.avoindata.fi/data/fi/api/3/action/status_show` · ~2,521 datasets
